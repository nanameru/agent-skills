# おすすめ記事リスト

note記事の末尾に入れる `## あわせて読みたい` の候補を管理するファイルです。

記事作成時は、ここからテーマに合う記事を2〜4本だけ選びます。CTA画像はこのおすすめ記事セクションの後、記事本文の一番最後に置きます。

## 追加フォーマット

```markdown
## <カテゴリ名>

- タイトル: <記事タイトル>
  URL: https://note.com/<user>/n/<article_key>
  使う場面: <Codex記事 / MCP記事 / note運用記事 / X運用記事 など>
  一言紹介: <なぜ読むとよいか>
```

## Codex / AI開発

- タイトル: Codexの2026年5月アップデートで何が変わったのか
  URL: https://note.com/meru2002/n/n80f65546b1d1
  使う場面: Codex、AIエージェント、開発ワークフロー、Appshots、Goal modeの記事
  一言紹介: Codexの新機能を実務目線で整理した記事。
