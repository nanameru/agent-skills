# 整理を実行する前の確認ケース

| 入力・状態 | 期待する動作 | 確認方法 |
|---|---|---|
| 作業状態を変えない「こんにちは」 | スキル読込も整理ツールも使わず返信1件 | 実Codexの隔離した新規ターンでtool call 0件を確認する |
| 作業状態を変えない「ありがとう」 | 同上 | 共通指示とSkillの省略条件を照合する |
| 「続けて」や承認待ちへの「それで実装して」 | 実作業を続け、省略扱いにしない | 共通指示とSkillの明示的な除外条件を照合する |
| 整理ツールが揃わないCLI | 整理だけのための探索・環境照会・一覧取得をしない | 利用可能ツールと省略条件を照合する |
| コード変更を完了し整理ツールも揃う | 現在IDだけを検証して既存手順で整理する | ID確認・他チャット保護の制約が残っていることを確認する |

この表の文章照合はモデルの動作保証ではない。実ハーネスの確認結果はGitHub Issue #37へ記録する。
自動整理のルールは既に開始したターンへ必ず遡及するとは扱わない。
