# Codexの共通入力を軽くする設定（Issue #39）

常時読むAGENTS.mdを小さくし、必要な場面でだけ詳細を読む。GitHub記録・コミット/push・必要な検証・安全制約は維持する。

## 配置

- `AGENTS.md` → `~/.codex/AGENTS.md`
- `agent-guides/*.md` → `~/.codex/agent-guides/`
- `AGENTS.before.md` は分割前の指示全文。通常の作業では読む必要はない。
- `section-map.json` は元の13節と7つの詳細ファイルの対応。

詳細ファイルを先に配置し、参照が有効になってからAGENTS.mdを置き換える。既存ファイルを変更する場合はバックアップを作り、同時変更を上書きしない。

## 今回の見直し

| 項目 | 結果 |
|---|---|
| 共通AGENTS.mdの常時部分 | 14,088 → 3,734 bytes（約73.5%縮小） |
| 元の詳細指示 | 全13節の文章を7ファイルに保持 |
| 本文と全補助ファイルが同一の重複 | 28種類の旧Codex登録をバックアップへ移動し、共通スキル側を維持 |
| codex-chat-wrapup | 旧パスが他の指示から参照されるため互換登録を維持 |
| terminal-browser | 2つの本文に差があるため維持 |
| Canva | ユーザーの指示でCodexのプラグインを無効化 |
| Slack・Gmail・Zoomなど | 維持 |
| モデル・推論設定 | 変更なし |

重複一覧は `deduplicated-skills.json`。旧登録の移動は元リポジトリやClaude Codeで使う実体を消す操作ではない。元のパス・リンク先・バックアップ先の対応はローカルのバックアップmanifestに記録した。

Canvaは `plugins."canva@openai-curated".enabled = false` のみを変更し、その他の全設定が構造上同じであることを確認した。アカウントや権限、サービス上のデータは変更していない。

## 軽い作業の記録

同じ判断・検証の記録は意味のある工程単位にまとめる。同じ版のスキルや手順はチャット内で再読しない。可逆的な小さな設定・文書変更には手動検証や構文確認を使い、無関係なアプリbuildや実装をなぞるだけのテストを追加しない。Issue・コミット/push・検証記録・進捗境界は省略しない。

## 検証

- 元の13節がsection-mapのいずれかに1回ずつ対応し、詳細ファイルの本文が元の各節と一致することを確認。
- インストールした常時指示と7詳細ファイルが、このディレクトリ内の対応ファイルと一致することを確認。
- 整理した28登録の全原本と必要なClaude参照が有効なことを確認。
- Canva以外の全設定の構造一致、モデルと推論設定の不変を確認。
- test-board TC-001（manual）とIssue #39へ記録。git diff --checkを実行。

この変更は指示とローカル登録の整理だけなので、プロダクトのbuild、iOS検証、アプリのテストは実行対象外。新しい自動CIを追加する変更も含めない。

バイト数の縮小は、トークン数・請求額・利用上限の削減率ではない。詳細を読む作業には引き続きその分の入力が必要。同一実体の重複が既に内部で統合されていた場合、登録の一本化だけでは使用量が変わらない可能性がある。実効入力と料金の差は、再起動後の新しい会話と同種作業のログで別途比較する。

## 復元

変更前の指示・設定と移動した登録は `~/.codex/config-backups/*-context-review/` にある。設定バックアップは認証情報を含み得るためローカルの権限を限定した場所だけに置き、GitHubへ載せない。

- 指示だけ戻す場合は、現在のAGENTS.mdも退避してから `AGENTS.before.md` またはローカルの変更前ファイルを戻す。
- 重複登録を戻す場合はローカルmanifestのoriginal/backupの対応を使い、既存パスや新しい変更を上書きしない。
- Canvaを再び使う場合は該当プラグインだけを再び有効にする。他の設定を含む古いconfig.tomlを丸ごと戻さない。
